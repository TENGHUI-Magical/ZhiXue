## 3. 集成场景

| 编号 | 场景 | 步骤 | 通过标准 |
| --- | --- | --- | --- |
| IT-FLOW-01 | 主链路 | 上传 → 轮询 SUCCESS → 建 DRAFT → 确认 → 讲解 → 推荐 | 每步 200；数据库状态依次正确；画像 dirty 标记写入 |
| IT-FLOW-02 | 低置信度 | 上传模糊图（confidence 0.6） | 字段返回但前端必须强制确认；不确认不能进入 CONFIRMED |
| IT-FLOW-03 | 重复确认 | 对同一 logId 连续确认两次 | 第二次返回 40900，数据未变 |
| IT-FLOW-04 | 计划打卡 | 生成周计划 → 打卡 3 题 | `done_count` 递增；重复打卡返回 40900 |
| IT-PRAC-01 | 作答提交 | 推荐题提交作答（带 recommendationId + clientToken） | `practice_record` 写入 source=RECOMMEND；`recommendation.is_adopted=1`；重复 token 返回首次结果且 `duplicate=true` |
| IT-SSE-01 | 心跳 | 建立 SSE 后 20s 不操作 | 至少收到一次 `: heartbeat`，连接不断 |
| IT-SSE-02 | 断开取消 | 收到首段文本后关闭客户端 | 上游 WebClient 订阅被取消；日志记录 latency 与已生成内容 |
| IT-SSE-03 | 首字节超时 | FastAPI 延迟 11s 才返回 | 前端 10s 中止并提示；服务端最终落库 |
| IT-SSE-04 | 断线恢复 | SSE 中断后用 explainId 查询 | 返回已生成全文与来源 |
| IT-DEG-01 | L1→L2 | Mock DeepSeek 返回 504 | 自动切 GLM；`degraded=true, level=L2` |
| IT-DEG-02 | 全失败→L3 | 两个模型都不可达 | 返回模板正文，含来源，`level=L3`，不白屏 |
| IT-DEG-03 | Redis 宕机 | 停 Redis 后请求讲解 | 跳过缓存直调模型，接口不 500 |
| IT-AUTH-01 | token 失效 | 手动改 token | 40100；前端清 token 并跳登录 |
| IT-UPLOAD-01 | 超大文件 | 上传 6MB 图 | 返回 40000，不进入 OCR 队列 |
| IT-REVIEW-01 | 教师评阅 | 提交分数 1–5 与评语 | 写回 `teacher_score/comment/reviewed_at`；重复评阅 40900 |
| IT-QUESTION-01 | 按知识点列题 | `GET /api/questions?kpId=KP0201&limit=5` | 返回 `qId/primaryKpId/questionType/questionText/difficulty`，不含答案与解析；limit 收敛，未知 kp 40400，缺参 40000 |

集成环境用 Testcontainers 起 MySQL 8 与 Redis 7（CI 的 GitHub Runner 自带 Docker）；**禁止连本地开发库**。若本机没有 Docker，按避坑 E1 先装 WSL2，或使用本地安装的 MySQL/Redis，但需在测试报告里注明环境差异。
