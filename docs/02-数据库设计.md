## 2. 关系

```text
course 1—N course_chapter 1—N knowledge_point
knowledge_point N—N knowledge_point (knowledge_prereq)
knowledge_point 1—N question_bank (primary_kp_id)
question_bank N—N knowledge_point (question_kp)
sys_user 1—N student_error_record / practice_record / study_plan / learning_portrait_snapshot
student_error_record 1—N ai_generation_log (log_id)
practice_record N—1 recommendation (recommendation_id)
study_plan 1—N study_plan_item
```

无物理外键；一致性由应用层/事务保证。

## 3. 关键口径

- `knowledge_point.concept_text` 300—500 字，RAG 检索与 L3 模板共用；`misconception` 不作为检索语料。
- `dimension_json` 只定义五维 key/name；知识点维度归属以 `knowledge_point.dimension_key` 为准。
- `practice_record.source`：`RECOMMEND / SELF / PLAN`；计划内作答走 checkin。
- `study_plan` / `study_plan_item` 当前无 `course_id`，单课程 MVP；多课程前需补列。
- `learning_portrait_snapshot` 无 `course_id`，当前读最新快照（**预留，无写入方**），实际走实时聚合；班级画像按课程题目实时聚合。
- `ai_generation_log.reviewed_at` 为空 = 待评阅；`teacher_score/comment/reviewed_at` 由教师评阅写回。
- `ai_generation_log.degrade_level` 只写 `L2/L3/L4`；L1 是主力模型，不写该字段。

## 4. 本地初始化

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"  # 不在 PATH 时用完整路径
$env:MYSQL_PWD = '<本地DB密码>'

& $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 -e "CREATE DATABASE IF NOT EXISTS zhixue DEFAULT CHARSET utf8mb4;"
Get-Content zhixue-server/sql/init-v2.sql -Raw | & $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 zhixue
Get-Content zhixue-server/sql/seed-kp-ch02-ch03.sql -Raw | & $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 zhixue
Get-Content zhixue-server/sql/seed-question-ch02-ch03.sql -Raw | & $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 zhixue
```

> PowerShell 不支持 `<` 重定向；用 `Get-Content -Raw | & $mysql`。cmd.exe 可直接用 `<`。
