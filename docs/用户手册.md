# 用户手册

## 学生

1. **登录**：学号/工号 + 密码。
2. **错题诊断工作台**：上传 JPG/PNG（≤5MB）或手动输入题干 → 选择错因 → 分析知识点 → 生成讲解。
3. **确认错题**：低置信度时先核对题干/知识点；确认后进入错题本。
4. **错题本**：按知识点/状态筛选；点“去练习”打开题目。
5. **先做后看**：单选/多选先选项，简答/编程先写思路；“查看参考答案”才显示答案与解析；看完自评“答对/答错”。
6. **推荐题**：来自最近一次已确认错题的巩固/变式/进阶三题；做完会标记“已采纳”。
7. **画像**：看五维雷达、薄弱点、错因分布；样本不足会提示“至少 3 次练习”。
8. **周计划**：点“生成本周计划”→ 7 天任务 → 每题“打卡”；完成后显示 DONE。
9. **知识图谱**：点节点看知识点详情；红色=当前画像薄弱点。

## 教师

1. 教师账号登录后，左侧菜单出现“教师评阅”。
2. 队列显示学生、知识点、错因、模型/降级、讲解摘要、时间。
3. 点“评阅”→ 查看讲解与引用来源 → 选 1—5 分 → 写评语 → 提交。
4. 同一条讲解只能评一次；重复提交提示“已评阅”（40900）。
5. 当前版本只做评阅，不做知识点/题库 CRUD（P1）。

## 状态与提示

| 提示 | 含义 | 下一步 |
| --- | --- | --- |
| 40100 | 登录过期 | 重新登录 |
| 40300 | 无权限 | 学生不能进教师页 |
| 40400 | 资源不存在 | 刷新/返回列表 |
| 40900 | 重复提交/已打卡/已评阅 | 不要重复点，刷新 |
| 42900 | 讲解太频繁 | 等待 `Retry-After` |
| 60001 | 概念切片为空，无法生成 | 联系教师补内容 |
| 60003 | 检索无匹配 | 手动选知识点或换题 |
| 60004 | 学术诚信拦截 | 改为自己的思路提问 |
