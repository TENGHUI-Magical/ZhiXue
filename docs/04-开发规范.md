# 04 · 开发规范

> 读者：全体开发（含接手 AI）。维护：PM。字数上限 4000。
> 权威序：`AGENTS.md` §3 红线 > 本文件 > 各模块 README。本文件只写**能改变行为、可验证**的规则；与 AGENTS.md 冲突时以 AGENTS.md 为准。
> 契约/错误码/算法口径分别见 `01-接口契约V2.md`、`03-错误码与降级.md`、`05-算法与规则设计.md`，本文件不复制其内容。

## 1. 分层职责（Java 模块化单体）

| 层 | 职责 | 禁止 |
| --- | --- | --- |
| Controller | 参数校验、鉴权入口、调用 1 个 Service、组装响应 | 业务分支、SQL、跨模块 Service 互调 |
| Service | 业务规则、事务边界、跨 Mapper 编排 | HTTP 细节、直接写响应流 |
| Mapper | 单表/聚合查询，SQL 全部 `#{}` 参数化 | 拼接用户输入、`.apply()`/`.inSql()`/`.last(用户输入)` |
| DTO/View | 出入参契约对象（record 优先） | 复用实体当出参、暴露内部字段 |

跨模块只调对方 Service（如 `plan → diagnosis.PracticeService`），不直接注入对方 Mapper。

## 2. 命名

- Java：类 `名词/名词短语`，方法 `动词+宾语`（`listByCourse`、`ensureOwnership`）；布尔 `is/has/can` 前缀。
- 表/列：蛇形单数（`practice_record`、`kp_id`）；实体驼峰 ↔ 列蛇形由 MyBatis-Plus 映射。
- Vue：组件 `PascalCase.vue`，组合式函数 `useXxx`，API 模块按领域拆（`api/diagnosis.ts`）。
- 常量：`static final` 业务上限（`WEAK_LIMIT`、`ERROR_LIMIT`）禁止魔法数散落。

## 3. 异常与日志

- 业务失败抛 `BizException(ErrorCode.X, "…")`，由 `GlobalExceptionHandler` 统一映射为 **HTTP 200 + code≠0**；不自造状态码。
- **禁止空 catch**：降级必须 `log.warn/error` 并写明原因与影响字段；只吞不记视为未完成。
- 日志脱敏：不打印 token/密码/身份证/手机号原文；学生姓名打码沿用 `TeacherStudentService.mask` 口径。
- 全链路带 `traceId`（`TraceIdFilter`），排查时以 `traceId` 串联，不在日志里写前端 session。

## 4. SQL 与数据

- 查询过滤下推到 WHERE，禁止全表捞出后在 Java 过滤；`IN` 集合必须有上界或由白名单 id 构成。
- 分页用 `COUNT + LIMIT #{limit} OFFSET #{offset}` 双查，size 钉在 1—50；排序字段走白名单 `Map`，不拼接列名。
- 事务放 Service（`@Transactional`），Mapper 不开事务；幂等靠唯一键 + 条件更新（如 `WHERE reviewed_at IS NULL`），不靠先查后插。
- schema 变更走版本化迁移脚本（`sql/init-vX.sql` / `*-migration.sql`），先备份、向后兼容、可重复执行。

## 5. 前端（Vue3 + TS）

- 数据全部走 `api/*` 模块（内部用 `request.ts`），组件不直接 `fetch`；token 统一读 `localStorage['satoken']`，不在组件里散写。
- 展示用 `{{ }}` 插值，**禁止 `v-html`/`innerHTML`**；动态样式用 `theme.css` 的 `--app-*` token，不写死颜色值（`#hex`/`rgb()`），新增颜色先加 token。
- 路由守卫 `meta.roles` 做第一道，服务端 `checkRole` 做真正权限；前端隐藏按钮 ≠ 权限。
- 空态/失败态必须给出可行动提示，禁止 `.catch(() => null)` 静默吞掉。

## 6. 测试

- 纯函数/算法必须有独立单测（`AnswerGrader`、`MasteryCalculator` 是模板）；修 bug 先写复现用例再修。
- Service 层用 Mockito 桩 Mapper，只验业务规则；SQL/聚合语义放 `IntegrationFlowTest`（`@Tag("it")`，CI `integration` 跑）。
- **断言值必须按当前公式手算核对**，不得沿用旧公式期望（掌握度是 Beta 后验，见 05 §2.3；旧公式 `1-Σsev/N` 已废弃）。
- 本地门禁（cwd 必须在 `zhixue-server` / `zhixue-ai` / `zhixue-web`，见 AGENTS.md §4）。

## 7. 提交

- 一次 commit 一个逻辑变更；消息 `feat|fix|test|docs|chore(scope): ...`；不混格式化/重命名。
- 提交前 `git status` 看两处（文档仓根 + `zhixue/`），不提交他人未提交改动。
- 测试数/体积/契约路径数**不在文档写死**，指向 surefire、`ceilings.json`、`openapi.yaml`。
