# 08 · 新人上手（2 小时目标）

> 目标：干净电脑按本文起 MySQL/Redis/Java/AI/前端，跑通一次“上传→OCR→映射→讲解→推荐”，并知道去哪里改。

## 1. 环境

| 项 | 版本/路径 |
| --- | --- |
| JDK | 21（本机 `D:\jdk-21.0.13.0.3`；Maven 默认 JDK17 会 class 65/61） |

| Node | 20+（本机 v22） |

| MySQL | 8.x，库 `zhixue` |
| Redis | 7.x |

## 2. 起库

```powershell
mysql -h 127.0.0.1 -u root -p --default-character-set=utf8mb4 -e "CREATE DATABASE IF NOT EXISTS zhixue DEFAULT CHARSET utf8mb4;"
mysql -h 127.0.0.1 -u root -p --default-character-set=utf8mb4 zhixue < zhixue-server/sql/init-v2.sql
mysql -h 127.0.0.1 -u root -p --default-character-set=utf8mb4 zhixue < zhixue-server/sql/seed-kp-ch02-ch03.sql
mysql -h 127.0.0.1 -u root -p --default-character-set=utf8mb4 zhixue < zhixue-server/sql/seed-question-ch02-ch03.sql
```

本地账号不要提交固定口令：`python tools/gen_dev_users.py --password '<自定义>'`，再执行生成的 `seed-dev-users.local.sql`。

## 3. 起 Java

```powershell
cd D:\Desktop\智学领航：高校课程学情诊断系统\zhixue\zhixue-server
```

健康检查：`GET http://127.0.0.1:8080/api/system/health`（db/redis/ai 三态，无鉴权）。

## 4. 起 AI

```powershell
cd D:\Desktop\智学领航：高校课程学情诊断系统\zhixue\zhixue-ai
D:\Python3.12.10\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 无 `DEEPSEEK_API_KEY` 时讲解会走 L3 模板；不影响启动。
- RAG 索引默认 `data/vector_index`；无 bge 模型时用字符 n-gram 兜底。
- 首次入库示例：

```powershell
curl -X POST http://127.0.0.1:8000/api/rag/embed -H "Content-Type: application/json" -d "{\"kpId\":\"KP0201\",\"text\":\"关系模型是...\",\"kpName\":\"关系模型\",\"courseId\":1}"
curl -X POST http://127.0.0.1:8000/api/rag/retrieve -H "Content-Type: application/json" -d "{\"text\":\"关系模型的三要素\",\"courseId\":1,\"topK\":5,\"threshold\":0.35}"
```

## 8. 常见坑

- 在 `zhixue` 根跑 `mvn` 会 `MissingProjectException`：必须进 `zhixue-server`。
- JDK 不是 21：`class file version 65/61`，重设 `JAVA_HOME`。
- `DB_PASSWORD` 未设：Java 启动失败；用环境变量，不写仓库。
- 8080 未起：前端所有请求失败；先看 `/api/system/health`。
- `40900` 不是系统故障：重复提交/打卡/评阅，刷新列表即可。
