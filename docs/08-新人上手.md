## 2. 起库

> 前提：MySQL 8.x 与 Redis 7.x 已安装并运行（版本见 §1）；本文不覆盖安装。

答辩/换机演示库（第1—5章 + 演示账号 + 演示数据）用统一入口，细节见 `docs/13-演示库恢复.md`：

```powershell
$env:DB_PASSWORD = '<本地DB密码>'
pwsh -ExecutionPolicy Bypass -File scripts/seed-demo.ps1
```

只做第2—3章竖切开发时，仍可按下面的手动导入：

```powershell
# 本机 mysql.exe 不在 PATH；没有 PATH 时用完整路径
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
$env:MYSQL_PWD = '<本地DB密码>'   # 避免 -p 提示与管道 stdin 冲突

& $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 -e "CREATE DATABASE IF NOT EXISTS zhixue DEFAULT CHARSET utf8mb4;"
Get-Content zhixue-server/sql/init-v2.sql -Raw | & $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 zhixue
Get-Content zhixue-server/sql/seed-kp-ch02-ch03.sql -Raw | & $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 zhixue
Get-Content zhixue-server/sql/seed-question-ch02-ch03.sql -Raw | & $mysql -h 127.0.0.1 -u root --default-character-set=utf8mb4 zhixue
```

> PowerShell 不支持 `mysql ... < file`（`<` 是保留运算符）；上面的 `Get-Content -Raw | & $mysql` 是等价写法。cmd.exe 可直接用 `<`。

本地账号不要提交固定口令：先 `pip install bcrypt`（`tools/gen_dev_users.py` 依赖），再 `D:\Python3.12.10\python.exe tools/gen_dev_users.py --password '<自定义>'`，最后按上面的 `Get-Content -Raw | & $mysql` 方式导入生成的 `seed-dev-users.local.sql`。

## 8. 常见坑

- 在 `zhixue` 根跑 `mvn` 会 `MissingProjectException`：必须进 `zhixue-server`。
- JDK 不是 21：`class file version 65/61`；不要直接 `mvn`，用 `..\scripts\mvn21.ps1`（pom 的 enforcer 会在 validate 阶段给出明确提示）。
- 脚本被执行策略拦截：当前会话执行 `Set-ExecutionPolicy -Scope Process Bypass`，或 `powershell -ExecutionPolicy Bypass -File ..\scripts\mvn21.ps1 -B -ntp verify`。
- `DB_PASSWORD` 未设：Java 启动失败；用环境变量，不写仓库。
- 8080 未起：前端所有请求失败；先看 `/api/system/health`。
- `40900` 不是系统故障：重复提交/打卡/评阅，刷新列表即可。
