## 5. 交接 Gate（8 项）

1. 干净电脑 2 小时起三服务。
2. 跑通上传→OCR→映射→讲解→推荐。
3. 加 1 个知识点 + 1 道题，前端可见。
4. 按 traceId 查到 `ai_generation_log`。
5. 回滚到上一提交并重启。
6. 备份 MySQL → 删表 → 恢复。
7. 断网 L3 / Redis 停降级。
8. 按文档独立完成 1—7。
