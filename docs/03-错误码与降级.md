# 03 · 错误码与降级

## 1. 统一响应

所有业务接口（SSE 除外）返回：

```json
{ "code": 0, "message": "success", "data": {}, "timestamp": 1793200000000 }
```

业务错误 **HTTP 200 + code≠0**，由 `GlobalExceptionHandler` 统一处理；前端 `request.ts` 解包 `code` 并抛 `ApiError`。

## 2. 错误码

| code | 含义 | 典型场景 |
| --- | --- | --- |
| 0 | 成功 | — |
| 40000 | 参数校验失败 | 缺参、越界、枚举非法、`page/size` 越界 |
| 40100 | 未登录/token 过期 | 无 `satoken` 或失效；前端清 token 跳登录 |
| 40300 | 无权限 | 学生访问教师接口、跨用户访问 |
| 40400 | 资源不存在 | 课程/知识点/题目/计划/讲解不存在 |
| 40900 | 重复提交/状态冲突 | 重复确认、重复打卡、重复评阅 |
| 42900 | 限流 | 讲解 10 次/分/用户；带 `Retry-After` |
| 50000 | 业务处理失败 | 兜底 |
| 60001 | L4 无法生成 | `concept_text` 为空 |
| 60002 | OCR 失败 | 识别失败 |
| 60003 | 检索无匹配 | `topK` 内最高分 < 0.35 |
| 60004 | 合规拦截 | 学术诚信词表命中 |

## 2.1 归属不明的讲解记录（P1-6）

“归属不明” = 讲解无法经 `student_error_record.log_id` → `question_bank.q_id` 定位到任何非空 `course_id`。

- **可见性**：创建者本人（学生）可凭 `explainId` 直读自己的讲解（`200 + code=0`）；评阅入口（队列 / 提交评阅）仅对课程归属教师开放；归属不明记录本轮**无人可评阅**——非创建者教师读取讲解详情或提交评阅一律 `40300`；记录不存在仍是 `40400`，不合并成 `40300`。
- **队列与导出**：评阅队列 COUNT、分页、CSV 导出共用同一段 WHERE（`EXISTS(q.course_id IS NOT NULL)` 保证可归属，`NOT EXISTS(q.course_id NOT IN 教师课程集)` 排除他课），归属不明记录不进入三者，保证“总数 / 分页 / 导出”同口径。
- **可归属记录不变**：能定位到课程的记录，原来可见的仍可见，原来 `40300` 的仍 `40300`。
- **角色缺口**：`sys_user.role` 目前只允许 `STUDENT/TEACHER`（openapi `allowableValues`），没有管理员角色；管理员放行需先升契约，本轮未实现。

## 3. 降级链（讲解）

| 级别 | 触发 | 行为 | 留痕 |
| --- | --- | --- | --- |
| L1 | 主模型完整产出 | DeepSeek 流式；失败重试 1 次 | `model=实际模型`（如 `deepseek-chat`），`degrade_level=null` |
| L2 | 有正文但非 L1 完整产出：①L1 失败后 GLM 完整产出；②任一远程模型流中断/超时截断，仅返回部分正文 | 保留已产出正文，**不追加**本地模板 | `model=实际产出模型`（如 `deepseek-chat` / `glm-4-flash`），`is_degraded=1`，`degrade_level=L2` |
| L3 | 远程零产出，完全回退本地模板（conceptText + misconception） | 只输出学习卡 | `model=local-template`，`degrade_level=L3` |
| L4 | `concept_text` 为空 | 不生成，返回 60001 | `model=none`，`degrade_level=L4`，`is_blocked=0` |

降级口径要点：

- L1/L2/L3 的唯一判定函数是 `RagExplainService#classifyDegrade`；AI 侧 `zhixue-ai/app/services/rag_service.py` 的 `LEVEL_L2/LEVEL_L3/MODEL_LOCAL_TEMPLATE` 常量与之同口径，任一侧改动必须同步另一侧。
- `model=local-template` 只在 L3（本地模板真正产出正文）时写；流中断/超时截断一律保留实际模型名，级别记 L2，不得记成 L3。
- 零正文且未能产出本地模板（首字节超时、客户端过早断开）：`degrade_level=L3`，`model` 保留实际值或 `unknown`，不伪造 `local-template`。
- 上游 `meta.model` / `degraded.modelUsed` 是服务间内部字段，仅用于留痕；SSE `degraded` 只暴露 `{level, reason}`，前端不消费模型名。
- `blocked`（60004 合规拦截）不算降级：`is_blocked=1`、`degrade_level=NULL`、`is_degraded=0`，`model` 保留实际值或 `unknown`；不要把它记成 L4 或任何降级级别。
- 存量数据：不回溯重分类，口径与复核方式见 §3.1；统计时需结合 `content_text` 长度与错误日志人工判断。

SSE 事件（公开契约）：`meta → source → delta* →（degraded）→ done`；错误用 `event:error`。上游 AI 服务内部事件是 `chunk`，Java 转发时统一转换为 `delta`，前端只消费 `delta`。`done` 可带 `cached`；`modelUsed` 在正常/降级时出现（缓存命中为 `cache`）。

### 3.1 存量数据口径声明（2026-11-04）

- 本次 L2/L3 判定修复**只作用于新增记录**；历史 `degrade_level='L3' AND model='local-template'` 的记录**不做批量重分类**。
- 原因：在本机全部含表库实测中，嫌疑行 `content_text` 最大 190 字符，`>200` 与 `>1000` 命中数均为 0，样本属演示种子文本或真本地模板，不存在大规模误标；**生产库规模未知**，需按下方 SQL 复核。
- 受影响面：教师端历史讲解仍可能按旧口径显示「本地教材知识卡」，统计中 L3 占比可能偏高。
- 若生产库复核出少量真实嫌疑（建议阈值 ≤50 条），**人工逐条确认后按 `log_pk` 精确修改**对应记录的 `degrade_level` 与 `model`；不写启发式批量脚本，不按时间窗或长度阈值批量改库。

生产库只读复核 SQL（**只读；勿在生产库执行任何 UPDATE/DELETE/ALTER**）：

```sql
-- 只读复核：建议使用只读账号执行，禁止任何写操作。
-- ① degrade_level 分布
SELECT degrade_level, COUNT(*) AS rows_cnt
FROM ai_generation_log
GROUP BY degrade_level
ORDER BY rows_cnt DESC;

-- ② L3 + local-template 嫌疑行数
SELECT COUNT(*) AS suspect_rows
FROM ai_generation_log
WHERE degrade_level = 'L3' AND model = 'local-template';

-- ③ 嫌疑行中正文长度 >200 与 >1000 的行数
SELECT
  SUM(CHAR_LENGTH(content_text) > 200)  AS gt_200,
  SUM(CHAR_LENGTH(content_text) > 1000) AS gt_1000
FROM ai_generation_log
WHERE degrade_level = 'L3' AND model = 'local-template';
```

## 4. 前端处理

- `40100`：清 `satoken/zhixue_user`，跳 `/login`。
- `40900`：提示“已提交/已打卡/已评阅”，刷新当前列表；不要自动重试。
- `40300`：提示无权限；教师页路由守卫只允许 `TEACHER`。
- `60001/60003/60004`：在讲解/检索区域显示可读文案与下一步（手动选题/重新生成/学术诚信提示）。
- 网络错误：显示“服务未启动/超时”，保留重试按钮。

## 5. 契约纪律

- 不新增魔法数字；错误码只从 `ErrorCode` 取。
- 新增错误码先改 `docs/01-接口契约V2.md` 与 `openapi.yaml`，再实现。
- 错误响应 `data` 目前为 `{}` 占位；前端不要依赖 `data` 结构。
