# 11 · 资源地图

| 位置 | 内容 |
| --- | --- |
| `zhixue-server/zhixue-bootstrap` | 启动、配置、健康检查 |
| `zhixue-server/zhixue-common` | `ApiResponse`、`ErrorCode`、全局异常 |
| `zhixue-server/zhixue-user` | 登录、角色、`UserQueryService` |
| `zhixue-server/zhixue-course` | 课程/章节/知识点/题库/题目详情 |
| `zhixue-server/zhixue-diagnosis` | 错题/OCR/诊断/讲解/推荐/画像/教师评阅 |
| `zhixue-server/zhixue-plan` | 周计划/打卡 |
| `zhixue-server/zhixue-notification` | 通知（未启用） |
| `zhixue-server/sql/` | DDL 与 seed |
| `zhixue-ai/app/routers/` | OCR/LLM/RAG 路由 |
| `zhixue-ai/app/services/rag_service.py` | 讲解/降级/SSE |
| `zhixue-ai/app/services/vector_index.py` | RAG 切片/向量/检索 |
| `zhixue-ai/data/vector_index/` | 向量索引持久化（不提交） |
| `zhixue-web/src/views/` | 学生 5 页 + 教师评阅 |
| `zhixue-web/src/api/` | 所有请求（页面不直写 URL） |
| `zhixue-web/src/styles/theme.css` | 主题 tokens、Element Plus 映射、全局动效 |
| `zhixue-web/src/components/` | `PageState`、`QuestionPracticeDrawer` |
| `zhixue/docs/` | 契约、算法、测试、本手册、runbook |
| `tools/` | 源码抽取、契约 diff、评测、testdata |

## 关键入口

- 登录：`/login`
- 学生：`/diagnosis`、`/error-book`、`/portrait`、`/plan`、`/knowledge-graph`
- 教师：`/teacher/reviews`
- 健康：`GET /api/system/health`
