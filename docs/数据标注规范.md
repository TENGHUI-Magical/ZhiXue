# 数据标注规范（知识点 / 题库）

> 目标：8 章 / 80 知识点 / 200—240 题；每条可追溯、可复核。当前 2 章 / 20 点 / 60 题。

## 1. 知识点字段

| 字段 | 要求 |
| --- | --- |
| `kp_id` | `KP` + 2 位章号 + 2 位序号，如 `KP0201`；人工录入不复用 |
| `course_id` | 单课程 MVP = 1 |
| `chapter_id` | 必须属于当前课程 |
| `name` | 专有名词，≤100 字；不用“概述/简介” |
| `concept_text` | 300—500 字；定义 → 条件/边界 → 一个最小例子 → 与相邻概念的区别 |
| `misconception` | 1—3 条，换行分隔；写“学生常把 X 当成 Y” |
| `textbook_page` | `Pxx` 或 `Pxx—Pyy`，必须能在教材核对 |
| `trial_hint` | ≤200 字，自检问题，不直接给答案 |
| `dimension_key` | 必须存在于 `course.dimension_json` |
| `sort_no` | 章内顺序 |
| `created_by` | 录入人 `user_id` |

## 2. 题库字段

| 字段 | 要求 |
| --- | --- |
| `q_id` | `Q_` + 2 位章号 + 2 位序号，如 `Q_0201` |
| `question_type` | 单选/多选/填空/简答/编程 |
| `question_text` | 题干完整；编程题给输入/输出/约束 |
| `options_json` | 选择题 `[{"key":"A","text":"..."}]`；非选择题 NULL |
| `answer_text` | 单选给字母；填空/简答给参考答案；编程给可运行代码或伪代码 |
| `analysis_text` | 为什么对、错项为什么错、易错点；≥80 字 |
| `difficulty` | 1 简单 / 2 中等 / 3 困难；每章保持 1:2:1 左右 |
| `source` | 教材/自编/改编，不写“网上” |
| `variant_hint` | 变式方向，≤200 字 |
| `question_kp` | 主关联 1 条 + 可选次要关联；`is_primary` 标记 |

## 3. 先修边

- `knowledge_prereq(kp_id, prereq_kp_id)`：`kp_id` 是后继，`prereq_kp_id` 是先修。
- 不建环；跨章边必须能解释（如 `KP0301 ← KP0205`）。
- 每个知识点至少 1 条入边或出边（首点除外）。

## 4. 三关质检

1. **排版关**：题干/选项/答案/解析字段齐全；无乱码；选项不重复。
2. **标签关**：知识点、维度、错因、难度正确；主关联与 `primary_kp_id` 一致。
3. **闭环关**：随机抽 10%，从题目能映射回知识点，从知识点能找到教材页码；映射 top1 准确率目标 ≥70%。

## 5. 生产流程

1. 按章建知识点草稿 → 人工对照教材核对页码/定义。
2. 按知识点出题 → 先自做一遍 → 写解析 → 第二人复核。
3. 批量 SQL/Excel 导入后跑 `SELECT COUNT(*)` 与抽样查询。
4. 只允许 AI 出草稿；**不得把模型生成的题目/解析直接入库**，必须人工复核签字。
5. 每次批量导入后备份数据库。
